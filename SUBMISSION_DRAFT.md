# Devpost submission draft — Nova

## Project name
Nova — Conversational Life Assistant

## Elevator pitch
A polished Alexa+ style assistant prototype that turns natural-language requests into useful daily planning and task actions.

## Description
Nova explores a conversational assistant experience that helps people organize tasks, understand priorities, and plan their next steps. Users can add and complete tasks through a dashboard or natural-language chat, request a contextual plan, and use optional browser speech input and read-aloud. The interface is designed to make the assistant’s state and actions visible rather than returning text alone.

This submission uses the simulated Alexa+ web experience path. It is an independent prototype, not an official Amazon product and not connected to Alexa+ services. The included source code runs locally with React and Vite. The prototype intentionally discloses when live services are not connected.
